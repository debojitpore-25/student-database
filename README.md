# Student Management System in C

A simple **console-based Student Management System** developed in C to manage student records using basic CRUD operations.

## Features

* Add student records
* Display all student records
* Search students by roll number
* Update student information
* Delete student records
* Menu-driven console interface

## Student Details

Each record contains:

* Roll Number
* Name
* Department
* Marks

## Concepts Used

* Structures (`struct`)
* Arrays
* Functions
* Loops and conditional statements
* `switch-case`
* String handling
* Basic CRUD operations

## How to Run

Compile using GCC:


```bash
gcc student_management.c -o student_management
```

Run the program:

```bash
student_management.exe
```

## Note

Student records are stored in memory, so all data is lost when the program exits. The system currently supports up to **100 students**.
